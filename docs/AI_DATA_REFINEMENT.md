# 로컬 AI로 데이터 다듬기 (맥미니)

2026-10-23 검토. 렛츠캠핑(`pyw31337/camp`의 `local/macmini`)처럼 맥미니의 무료·오프라인 AI
(Apple Vision, Ollama)로 매일 모으는 공연 데이터를 더 정확하게 만들 수 있는지 살펴본 결과와 계획입니다.

## 1. 같은 공연이 여러 번 보이던 문제 (이번에 고침)

### 원인
`src/lib/performance-merger.ts`는 `제목 + 공연장 + 시작일`이 **글자 그대로 같을 때만** 합쳤습니다.
같은 공연인데 출처마다 표기가 달라 따로 남았습니다.

| KOPIS | 인터파크 / 타임티켓 |
|---|---|
| 늘근도둑이야기 [대학로] @ 아트포레스트 | 연극〈늘근도둑이야기〉 @ 대학로 아트포레스트 |
| 국립발레단, 지젤 @ 예술의전당 | 국립발레단 〈지젤〉 @ 예술의전당 오페라극장 |
| 그날들 [이천] | 뮤지컬 〈그날들〉 - 이천 |

배포 데이터(9,840건)에서 출처 간 중복을 세어 보니 약 **760건**이었습니다(대부분 KOPIS↔인터파크).

### 해결: `src/lib/cross-source-dedupe.ts`
`generate-data`에서 기존 병합 바로 뒤에 실행됩니다. AI 없이 동작하므로 GitHub Actions 폴백에서도 같은 결과가 나옵니다.

1. **남길 카드 우선순위**: KOPIS → 문화포털 → 서울문화포털 → 인터파크 → YES24 → 타임티켓.
   예매처 목록을 모두 가진 KOPIS·문화포털 카드가 남습니다.
2. **같은 공연으로 보는 기준** (위에서부터 확실한 순)
   - KOPIS 예매처 목록에 인터파크 상품번호·타임티켓 번호·YES24 번호가 그대로 있음 + 기간이 겹침 → 확정.
     (예매처 링크로 확정된 쌍을 표본으로 검토했는데, 제목이 완전히 달라도 잘못 합친 경우는 없었습니다.)
   - 공연장이 같음(이름 포함 관계·같은 venueKey·400m 이내) **그리고** 정리한 제목이 같음 + 기간이 겹침 → 확정.
   - 공연장이 같음 + 제목이 비슷함(〈〉 안 제목, ` - 지역` 앞부분, `시리즈, 제목` 뒷부분, 글자 유사도 ≥ 0.75) + **시작일·종료일이 같음** → 확정.
   - 제목이 어느 정도만 비슷함 → 합치지 않고 **애매한 쌍(gray zone)**으로 남김 → 아래 AI 판정 대상.
   - 같은 출처끼리는 합치지 않습니다. 투어 공연(도시마다 공연장이 다름)과 월별 회차(정오의 음악회 10월/11월)는 공연장·날짜 조건 때문에 따로 남습니다.
3. **합치는 방법**: 남는 카드에 빠진 정보(가격·가격표·출연·관람시간·연령 등)를 채우고,
   지워지는 판매처 페이지는 **예매처 버튼으로 추가**합니다(중복 링크는 상품번호로 걸러냄).
   KOPIS 가격이 `정보없음`이면 판매처 가격을 씁니다.
4. **기존 공유 링크 유지**: 지워진 카드의 id는 `aliasIds`에 남아 `#p=<옛 id>` 링크가 합쳐진 카드를 엽니다.
   인터파크 회차 달력(`sessions.json`)도 KOPIS 카드의 예매처 링크에서 상품번호를 찾아 그대로 붙습니다.

현재 `src/data`로 만들면 639건이 합쳐지고, 58쌍이 애매한 쌍으로 남습니다(로그: `Cross-source duplicates merged`).

## 2. 애매한 쌍은 로컬 AI가 판정 (이번에 추가)

`scripts/ai/judge-duplicates-ollama.ts` — 맥미니 스케줄(`local`, `local-light` 계획 맨 끝)에서 선택 단계로 돕니다.

- 직전 배포 데이터에서 애매한 쌍을 찾아, 아직 판정하지 않은 쌍만 Ollama에 묻습니다(1회 최대 80쌍·15분).
- 결과는 `src/data/ai-dedupe-judgments.json`에 저장·커밋됩니다. 다음 `generate-data`가 `same && confidence ≥ 0.8`인 쌍만 합칩니다.
  GitHub Actions는 모델을 돌리지 않고 이 파일만 읽습니다.
- Ollama가 꺼져 있거나 모델이 없으면 아무것도 바꾸지 않고 넘어갑니다. 실패해도 데이터 갱신을 막지 않습니다.
- 판정은 120일 지나면 지워져 다시 묻습니다.

설치(맥미니에서 한 번):

```bash
brew install ollama && brew services start ollama
ollama pull qwen2.5:7b          # 기본값. 메모리 16GB 이상
# 한국어를 더 잘 읽는 대안: ollama pull exaone3.5:7.8b  → OLLAMA_MODEL=exaone3.5:7.8b
npx tsx scripts/ai/judge-duplicates-ollama.ts   # 바로 한 번 돌려 보기
```

환경변수: `OLLAMA_HOST`, `OLLAMA_MODEL`, `AI_JUDGE_MAX_PAIRS`, `AI_JUDGE_MAX_SECONDS`.

## 3. 더 정교하게 다듬을 수 있는 것 (다음 후보, 효과 큰 순)

배포 데이터 기준 현황: 공연 계열 4,620건 중 관람연령 없음 2,970 · 관람시간 없음 2,944 · 출연 없음 3,503 · 가격 없음 2,719,
설명이 `…에서 열리는 특별한 … 공연/행사입니다` 틀 문장인 카드 3,474건. 소개 이미지(`synopsisImages`)가 있는 공연 카드 1,750건.

| # | 작업 | 도구 | 기대 효과 |
|---|---|---|---|
| 1 | **소개 이미지 글자 읽기**: KOPIS·인터파크 상세 이미지에서 출연진·관람시간·연령·가격표·프로그램(곡목)을 뽑아 빈 칸을 채움 | Apple Vision OCR(`camp/local/macmini/vision-ocr.swift` 재사용) → Ollama로 항목 추출(JSON 스키마) | 관람시간·연령 누락 수천 건 감소, `validate:details`의 인터파크 누락 임계값 경고 해소 |
| 2 | **설명문 다시 쓰기**: 틀 문장 대신 OCR·원문 소개에서 2~3문장 요약 | Ollama(qwen2.5 / exaone3.5) | 상세 화면과 검색 품질 향상 |
| 3 | **태그 붙이기**: 아동·가족, 내한, 초연·앙코르, 무료, 마지막 공연 등 | Ollama, 근거 문장과 함께 저장 | 추천·필터 정확도 |
| 4 | **포스터 확인**: 글자만 있는 배너·기본 이미지·다른 공연 포스터를 걸러 냄 | Apple Vision 장면 분류 + `qwen2.5vl` | 카드 이미지 품질 |
| 5 | **공연장 이름 맞추기**: 사전에 없는 공연장 이름을 기존 공연장 후보 중에서 고름 | Ollama + 카카오 장소 후보 | 좌표 누락·지도 오표시 감소 |
| 6 | **대량 후보 찾기**: 출처가 더 늘면 제목 임베딩으로 비슷한 쌍을 미리 찾음 | Ollama `bge-m3` 임베딩 | 중복 판정 범위 확장 |

### 지킬 원칙 (렛츠캠핑과 같게)
- AI 결과는 **캐시 파일**(`src/data/ai-*.json`)로 커밋하고, 화면 데이터는 `generate-data`가 그 파일을 읽어 만듭니다. CI는 읽기만 합니다.
- 원본을 덮어쓰지 않고 **빈 칸만 채웁니다**. 확신도 기준을 넘는 것만 쓰고, 근거(원문 줄)를 함께 저장합니다.
- 맥미니 작업 시간(평일 18:00~08:00, 주말)과 기존 스케줄 잠금을 따르고, 시간 예산 안에서 나눠 처리합니다.
- AI 단계는 모두 `optional`: 실패해도 데이터 갱신은 그대로 진행합니다.
