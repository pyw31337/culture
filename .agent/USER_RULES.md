# User Rules & Preferences

These rules apply to all tasks and interactions in this project.

1.  **Language**: Always provide a detailed explanation in **Korean** at the end of every response.
2.  **Progress Tracking**: For long-running operations, explicitly visualize progress (e.g., "Processing... [20%]", "Step 1/5 complete") or use frequent status updates to indicate the current state.
3.  **Auto Git Update**: Upon completing a fix or code modification, **automatically** commit and push the changes to GitHub.
4.  **Validation**: Always validate the process and results of any data collection (scraping).
    - Run validation scripts (e.g., `validate-images.ts` or data integrity checks) immediately after scraping.
    - Ensure data quality before committing.
5.  **Persistence**: These rules are permanent for this project.
